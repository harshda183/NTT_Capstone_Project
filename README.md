## Personalized box
- Starting row: 18
- Height: 20 screen rows
- Width: 48 pixels (3 words per row)
- Position: left edge
- Behaviour: black while a key is pressed; cleared after release

## Files
- `CPU.hdl`, `Memory.hdl`, `Computer.hdl`: top-level Hack computer chips.
- `assembler.py`: two-pass Python Hack assembler.
- `Box.asm`: assembly program that draws and clears the box.
- `Box.hack`: machine code generated by the assembler.
- `symbols.txt`: labels, predefined symbols and variables with addresses.
- `Capstone_Report.docx`: formatted report with places to insert genuine screenshots.

## Run the assembler
Open a terminal in this folder and run:
```bash
python assembler.py Box.asm
```
It generates/overwrites `Box.hack` and `symbols.txt`.

## Run in the Nand2Tetris tools
1. Open the HDL folder in the Hardware Simulator and load `CPU.hdl`, `Memory.hdl`, and `Computer.hdl` with the standard Nand2Tetris chip library available.
2. Run the official `CPU.tst`, `Memory.tst`, `ComputerAdd.tst`, `ComputerMax.tst`, and `ComputerRect.tst` tests. Capture screenshots of the actual PASS results.
3. Open `Box.asm` in the CPU Emulator. Load `Box.hack` as the machine program (the CPU Emulator may also assemble `.asm` files itself, but use the supplied `.hack` to demonstrate your own assembler).
4. Run the program. Press any key: the 48-by-20 black rectangle should appear at row 18. Release all keys: the rectangle should disappear.
5. Capture a screenshot of the actual screen with the box visible.

**Important:** HDL test screenshots and emulator screenshots must be captured from your own Nand2Tetris installation. They are not fabricated or included as if tests had been run here.
